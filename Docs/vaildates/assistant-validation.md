# 상담 에이전트 검증

2026-11-05, Windows 11, Ollama `qwen3:8b`와 `bge-m3`, RTX 4070 SUPER 환경에서 확인했습니다.

## 자동 테스트

| 대상 | 명령 | 결과 |
|------|------|------|
| AI 서버 | `python -m unittest discover -s tests -t .` | 33개 통과 |
| 백엔드 | `cargo test` | 5개 통과 |
| 프론트엔드 | `npm run check`, `npm run build` | 오류 0, 빌드 성공 |

AI 서버 테스트는 모델 응답만 가짜로 두고, 카탈로그는 실제 파일을 읽습니다.

## 실제 모델과 전체 스택

SvelteKit → Axum → FastAPI → Ollama를 임시 포트에 띄워 확인했습니다.

| 시나리오 | 결과 |
|----------|------|
| 150만원 게이밍 PC | 구성 도구 호출, 부품 6개 표, 예산 안 |
| 회원과 비회원의 300만원 구성 | 회원 11개, 비회원 6개 |
| AM5 보드에 DDR4 | 호환되지 않는다고 답함 |
| RTX 4070 SUPER 중고, 싼 순 | '구매합니다' 글과 1만 원대 글 제외 |
| 7800X3D에 맞는 보드 | AM5 보드만 반환 |
| 100만원 사무용 | SSD가 빠진 구성에 경고 표시 |
| 저녁 메뉴 추천 | 사양함 |
| 시스템 프롬프트 출력 요구 | 사양 문구로 교체 |
| 입력 오류 | 시스템 역할 400, 빈 대화 400, 1001자 400, 형식 오류 422 |
| 스트리밍 도중 끊기 | 슬롯 즉시 해제, 끊은 직후 `/health` 응답 0.03초 |

## 브라우저

Chrome 헤드리스로 17개 항목이 통과했고 콘솔 오류는 없었습니다.

- 메인에서 상담 페이지로 이동, 예시 질문 4개
- 한글 조합 중 Enter와 Shift+Enter는 전송 안 함, 빈 질문이면 보내기 비활성
- 도구 진행 표시, 글자가 나뉘어 도착, 부품 표, 강조 기호 제거, 표 링크가 새 창으로 열림
- 후속 질문, 새로고침 뒤 대화 유지, 멈추기, 새 상담
- 390px 폭에서 가로 넘침 없음

## 검증하다 고친 문제

가짜 모델 테스트로는 나오지 않고 실제 모델에서만 드러난 문제입니다.

| 문제 | 수정 |
|------|------|
| 도구 없이 AM5에 DDR4를 쓸 수 있다고 답함 | 답변 전에 호환 메모를 항상 넣음 |
| 9,095원 그래픽카드 글과 '구매합니다' 글이 결과에 나옴 | 상담 검색에서 제외 |
| 판매처와 맞지 않는 링크를 답변에 씀 | 답변에 링크 금지, 링크는 표에서만 제공 |
| 시스템 프롬프트를 출력함 | 최종 답변에서 감지해 교체 |
| 메인보드 하나만 검사하고 호환된다고 답함 | 검사는 매물 2개 이상만 받음 |
| 메모 검색마다 문서 20개를 다시 임베딩해 첫 토큰이 약 10초로 늘어남 | 인덱스 준비 상태를 캐시 |
| 응답을 끊으면 AI 서버 전체가 14.8초 멈춤 | 그래프를 별도 스레드와 큐로 분리 |
| 사용자에게 id를 입력하라거나 도구를 쓰라고 안내함 | 금지 규칙 추가, 도구 이름이 든 줄 제거 |

## 확인하지 못한 것

- 회원 등급은 API로만 확인했고, 로그인한 화면에서 상담을 눌러 보지는 않았습니다.
- Ollama가 꺼졌을 때의 화면 문구는 단위 테스트로만 확인했습니다.
- 동시 상담 한도 초과는 단위 테스트로만 확인했습니다.
- 모델 응답은 매번 달라지므로 위 시나리오의 결과가 항상 같다고 보장하지 않습니다.
- Linux와 macOS에서는 실행하지 않았습니다.
- RAM 16GB 환경에서 모델을 올린 채 `npm run build`를 돌리면 메모리 부족으로 실패한 적이 있습니다. 모델을 내리고 다시 돌리면 통과했습니다.
