# 상담 에이전트

사용자가 질문하면 로컬 언어 모델이 카탈로그와 호환 메모를 직접 찾아보고 답하는 대화 기능입니다. 화면은 `/assistant`(메뉴의 **상담**)입니다.

## 흐름

```
/assistant ──▶ Axum POST /api/chat ──▶ FastAPI POST /agent/chat ──▶ LangGraph (think ⇄ act) ──▶ Ollama
             토큰으로 회원 등급 결정          줄 단위 이벤트(NDJSON)를 그대로 전달
```

| 위치 | 하는 일 |
|------|---------|
| [assistant.py](../../ai-server/app/agents/assistant.py) | 도구 호출 루프, 도구 4개, 답변 후처리 |
| [routes/assistant.rs](../../backend/src/routes/assistant.rs) | 입력 검증, 회원 등급 결정, 스트림 전달 |
| [assistant/+page.svelte](../../frontend/src/routes/assistant/+page.svelte) | 대화 화면 |

## 도구

모두 읽기 전용입니다. 구매, 저장, 파일 쓰기는 하지 않습니다.

| 도구 | 하는 일 |
|------|---------|
| `search_parts` | 판매 중인 매물 검색. 같은 모델은 가장 싼 한 줄만 돌려줌 |
| `recommend_build` | 용도와 예산으로 호환되는 구성 생성. 언어 모델 없이 기존 추천 규칙을 씀 |
| `check_compatibility` | 매물 2개 이상의 소켓, 메모리, 파워, 크기 규칙 검사 |
| `search_knowledge` | 호환 메모 검색 |

## 환각을 줄이는 장치

작은 모델은 규칙을 적어 줘도 어기는 경우가 있어, 중요한 것은 서버 코드로 처리합니다.

| 장치 | 이유 |
|------|------|
| 답변 전에 호환 메모를 항상 넣음 | 도구 없이 "AM5에 DDR4 가능"이라고 답한 사례가 있었음 |
| 부품 표는 도구 결과로만 만듦 | 답변의 이름과 금액이 틀려도 표는 실제 데이터임 |
| 도구 결과에 없는 금액은 경고 | 조회 결과나 질문의 금액과 5% 넘게 다르면 표시함 |
| 필수 부품이 빠진 구성은 경고 | 예산이 모자라면 SSD 없는 구성이 나올 수 있음 |
| 다른 부품 이름으로 찾으면 소켓으로 찾아 규칙까지 검사 | "7800X3D에 맞는 보드"를 한 번에 찾다 0건으로 포기한 사례가 있었음 |
| 프롬프트 유출과 도구 이름 줄 제거 | 최종 답변 단계에서 처리함. 스트리밍 중에는 잠깐 보일 수 있음 |

## 등급과 저장

| 항목 | 비로그인 | 회원 |
|------|----------|------|
| 구성 부품 수 | 핵심 6개 | 11개까지 |
| 메모와 우선순위 반영 | 안 함 | 함 |
| 대화 저장 | 브라우저 탭(`sessionStorage`)에만 | 브라우저 탭에만 |

대화는 서버와 DB에 저장하지 않습니다. 탭을 닫으면 사라지고, 기록 페이지에도 쌓이지 않습니다.

## 실행

Ollama를 켜고 도구 호출을 지원하는 모델을 받아 둡니다. `OLLAMA_MODEL`을 먼저 찾고, 없으면 설치된 로컬 모델 가운데 도구 호출을 지원하는 것을 씁니다. 이름에 `cloud`가 들어간 모델로는 대화를 보내지 않습니다.

```bash
ollama pull qwen3:8b
ollama pull bge-m3
```

단위 테스트는 Ollama 없이 돕니다.

```bash
cd ai-server
python -m unittest discover -s tests -t .
```

## API

`POST /api/chat`

```json
{ "messages": [{ "role": "user", "content": "150만원으로 게이밍 PC 맞춰 줘" }] }
```

| 조건 | 응답 |
|------|------|
| 정상 | `200`, `application/x-ndjson` |
| 마지막 차례가 질문이 아님, 질문 1000자 초과, `user`·`assistant` 외의 역할 | `400` |
| 본문 형식 오류 | `422` |
| AI 서버 연결 실패 | `502` |

`Authorization: Bearer <토큰>`이 유효하면 회원 등급으로 처리합니다. 최근 12개 차례만 모델에 넘깁니다.

응답은 한 줄에 이벤트 하나입니다.

| `type` | 내용 |
|--------|------|
| `start` | `model` |
| `tool` | `name`, `label`. 이 이벤트가 오면 지금까지 받은 글은 버립니다 |
| `tool_result` | `name`, `summary` |
| `token` | `text` |
| `done` | `answer`, `parts`, `warnings`, `model`, `tool_rounds`. 화면 글은 `answer`로 바꿉니다 |
| `error` | `message`. 모델 없음, 동시 처리 초과, 시간 초과는 상태 코드 `200` 안의 이 이벤트로 옵니다 |

## 제한값

| 항목 | 값 |
|------|-----|
| 동시 상담 | 2건. 넘으면 `error` 이벤트 |
| 한 질문의 도구 호출 | 4라운드, 라운드당 4개 |
| 한 답변의 시간 | 240초 |

## 알려진 한계

- 답변 문장의 품질은 모델에 달려 있습니다. "중고 제품으로 소음을 낮춤"처럼 근거 없는 설명이 섞일 수 있으니 표와 경고를 기준으로 봅니다.
- 같은 질문도 도구를 고르는 방식이 매번 다를 수 있습니다.
- 호환 규칙은 규격 값이 있는 매물만 검사합니다. 중고 판매글은 규격이 비어 있는 경우가 많습니다.
- '삽니다' 글과 비정상 저가 글 제외는 상담 검색에만 적용됩니다. 목록과 기존 추천에는 적용하지 않았습니다.
- 추천 규칙(`_assemble`)이 보드에 예산을 많이 써서 예산이 빠듯하면 SSD가 빠질 수 있습니다. 상담은 경고만 띄우고 규칙은 고치지 않았습니다.
