## 변경 내용

- LangGraph `think ⇄ act` 루프로 된 상담 에이전트 추가. 도구는 매물 검색, 구성 짜기, 호환 검사, 호환 메모 검색 4개이고 모두 읽기 전용이다.
- `POST /agent/chat`이 진행 이벤트를 NDJSON으로 흘려보낸다. `/health`에 `assistant_active`를 추가.
- Ollama 스트리밍 호출과 도구 호출 지원 로컬 모델 선택을 추가. 클라우드 모델은 고르지 않는다.
- 카탈로그 검색 추가. 같은 모델은 가장 싼 한 줄만 남기고, 상담 검색에서는 '삽니다' 글과 비정상 저가 글을 뺀다.
- 호환 메모 사전 주입, 금액 검증, 필수 부품 누락 경고, 프롬프트 유출 차단을 서버 코드로 처리한다.
- 그래프는 별도 스레드에서 돌려, 호출자가 끊어도 서버가 멈추지 않는다.

## 변경 이유

언어 모델이 추천 설명과 메모 해석에만 쓰여 사용자가 직접 대화할 수 없었다. 사용자 요청: LLM 기능을 직접 쓸 수 있는 에이전트 봇 추가.
