## 변경 내용

- 회원가입, 로그인, 토큰, 내 정보, 추천 기록 API를 추가한다.
- 기준 카탈로그와 `live.json`을 합쳐 목록을 돌려준다. 단종·판매완료·판매예정·링크 없음 매물은 목록 뒤에서 구분된다.

## 변경 이유

목록과 추천을 프론트가 직접 파일이나 AI 서버에 붙지 않고 백엔드를 거치게 하려고 한다. 판매가 끝난 매물은 화면에서 연하게 보여줄 수 있게 상태 값을 응답에 포함한다.
